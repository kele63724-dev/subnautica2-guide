# 乗り物

入手推奨順：**ウェイクメーカー → タッドポール → 潜水エレベーター**。

![乗り物能力比較](/images/vehicles/vehicle-comparison.svg)

---

## タッドポール (Tadpole)

| 属性 | 値 |
|------|-----|
| **段階** | 序盤-中盤 |
| **基本深度** | 250m |
| **最大深度** | 400m+（Mk.2） |
| **速度** | 速い |
| **特徴** | モジュール式、シャーシ交換可 |

Subnautica 2 の主力乗り物。単座モジュール式潜水艇。

**解除**：タッドポールの破片 3 つスキャン。

**クラフト**：チタンインゴット × 2 + ガラス × 1 + システムチップ × 1 + パワーセル × 1

### シャーシ変種

| シャーシ | 材料 | 用途 |
|----------|------|------|
| スカウトレイ | プラスチール×2 + 高性能配線キット×1 + 専用コア×1 + 強酸×1 | 高速偵察 |
| ホール（輸送） | チタンインゴット×4 + ストロンチウム×3 + エナメルガラス×3 + 専用コア×1 | 大容量収納 |

### アップグレード優先順位

1. **深度 Mk.1** — 300m+、珊瑚礁帯深部へ
2. **エンジン効率** — 航続時間延長
3. **衝撃装甲** — ニードラー等の攻撃軽減
4. **深度 Mk.2** — 400m+、遺跡群・遊牧端域へ
5. **静音推進** — コレクターリバイアサン領域通過用
6. **光起電力充電器** — 浅海域でソーラー充電

## ウェイクメーカー (Wakemaker)

| 属性 | 値 |
|------|-----|
| **段階** | 序盤 |
| **深度** | 酸素タンク依存 |
| **速度** | 中-速 |
| **特徴** | 装着式、即時使用 |

装着式水中推進器。

**クラフト**：銀 × 1 + グリース × 1 + 基本バッテリー × 1 + 配線キット × 1

- ✓ 安全な浅瀬での高速移動
- ✓ 資源採集往復
- ✗ 酸素供給なし
- ✗ 収納なし
- ✗ 防御なし

---

## 潜水エレベーター (Dive Elevator)

| 属性 | 値 |
|------|-----|
| **段階** | 中-終盤 |
| **深度** | 300m+ |
| **速度** | 垂直方向のみ |
| **特徴** | 基地間輸送、資源吊り上げ |

- ✓ 高速垂直昇降
- ✓ 基地と深海前哨を接続
- ✓ 大容量資源輸送
- ✗ 垂直移動のみ
- ✗ 軌道敷設が必要
