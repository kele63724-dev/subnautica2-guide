## S 級脅威 — リバイアサン

### コレクターリバイアサン (Collector Leviathan)

| 属性 | 値 |
|------|-----|
| **体長** | 50m+ |
| **分類** | リバイアサン（頭足類） |
| **生息地** | 荒涼平原、外縁境界 |
| **攻撃** | 4 本の触手 — 掴み/圧壊/叩き/衝撃波 |
| **AI** | リアルタイム動的評価、固定スクリプトではない |

**EA 唯一の攻撃的リバイアサン。倒せない（設計上）。**

**対処法**：
- 🛡️ **45,000 ユニット**の距離を取ると消失判定
- 🛡️ **囮フレア**で注意を一時的に逸らす
- 🛡️ タッドポールの**静音推進**で探知リスク低減
- ❌ 戦おうとするな

## 小型生物

### ムーンフィッシュ科

| 名称 | 用途 |
|------|------|
| **ハーフムーン** | 基本食料 |
| **ブルームーン** | 食料、ハーフムーンと群れる |
| **ハーベストムーン** | 三日月巻きの核心材料 |

**三日月巻き** = ハーフムーン + ブルームーン + ハーベストムーン + 繊維パルプ。最強の初期食料。
