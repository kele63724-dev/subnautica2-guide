# 生物群系

抢先体验版开放 **6 大生物群系**，位于 Ariadne Arm 星域。最终地图将大于初代 + 零度之下总和。

![生物群系深度分布图](/images/biomes/biome-depth-map.svg)

---

## 海藻森林 (Kelp Forest)

| 属性 | 值 |
|------|-----|
| **深度** | 0 - 60m |
| **危险等级** | 🟢 安全 |
| **核心资源** | 钛、铜、石英、盐、路西法腐囊 |
| **敌对生物** | 无大型掠食者 |

出生点所在的安全区。光照充足，基础资源密集。金属废料回收钛的最佳地点。

**关键地标**：
- 救生舱起始点
- 天使栉（消化适应 + 耐热基因采样点）
- 路西法腐囊采集区（方向 120°，约 84m）

---

## 珊瑚礁带 (Coral Gardens)

| 属性 | 值 |
|------|-----|
| **深度** | 0 - 200m |
| **危险等级** | 🟡 低-中危 |
| **核心资源** | 石英（珊瑚穹顶内大量）、银、金、硫、铜、铅 |
| **敌对生物** | 少量攻击性小型生物 |

前期最重要的资源区。彩色发光珊瑚群落，包含多个子区域：

| 子区域 | 特点 | 关键资源 |
|--------|------|----------|
| **浅滩 (Shallows)** | 0-50m，珊瑚穹顶 | 石英 (蜘蛛穹顶有 ~100 个节点) |
| **水母荒原 (Jelly Barrens)** | 50-200m，死水母地标 | 铜、坏死囊 |
| **海葵丘陵 (Anemone Hills)** | 浅-中深度 | 银、坏死囊、耐热基因采样点 |
| **砂岩山脊 (Sandstone Ridges)** | 浅-中深度，西北方向 | 铅（最可靠来源） |
| **凝灰岩塔 (Tufa Towers)** | 浅-中深度 | 巨颚利维坦、多处残骸 |
| **Zezuran 沙漠 / 墓地** | 中等深度，热洞 200-250m | 金、硫、锂 |

::: tip 石英获取
珊瑚穹顶是橙色球体结构，深度 10-30m。每个穹顶出 3-8 块石英。**蜘蛛穹顶**（方向 240-245°，距救生舱 ~220m）内部有近 100 个小型石英节点。
:::

## 稀疏平原 (Sparse Plains)

| 属性 | 值 |
|------|-----|
| **深度** | 100 - 300m |
| **危险等级** | 🔴 高危 |
| **核心资源** | 铜、钛、铅 |
| **敌对生物** | ☠ 收藏家利维坦 (Collector Leviathan) |

开阔无遮挡的平原区域。**收藏家利维坦的专属栖息地**。

::: danger 收藏家利维坦对策
- 体长 50m+，鱿鱼形态，4 条触手（抓取/碾压/抽打/心理压迫）
- **无法击杀**（设计如此），只能规避
- 实时 AI 动态评估你的位置，不是固定巡逻脚本
- **逃离方法**：创造 45,000 单位距离触发其消失，或用**诱敌照明棒/诱饵弹**临时转移注意
- 建议乘蝌蚪号快速通过，不要停留
:::

## 热液喷口区 (Hydrothermal Vents)

| 属性 | 值 |
|------|-----|
| **深度** | 150 - 300m+ |
| **危险等级** | 🔴 高危 |
| **核心资源** | 金、硫、锂（Zezuran 热洞 200-250m 紫色晶体） |
| **敌对生物** | 耐高温特殊生物 |

深海高温区域，富集矿物。**需耐热基因**才能安全进入。

**关键地标**：
- Zezuran 沙漠热洞 — 锂矿最佳来源，紫色晶体附着洞壁
- 橙色水体标志高温区
- 建议蝌蚪号深入探索

## 遗迹废墟 (Overgrown Ruins / Axum Region)

| 属性 | 值 |
|------|-----|
| **深度** | 200 - 400m+ |
| **危险等级** | 🟠 中-高危 |
| **核心资源** | 天青石 (Celestine)、氯铜矿 (Atacamite)、传导晶体 |
| **敌对生物** | 针刺者 (Needler Mango) |

被植被覆盖的远古先驱者建筑。藏有**高级蓝图和剧情线索**。距离救生舱约 1,000m 向东。

| 子区域 | 深度 | 特点 |
|--------|------|------|
| **Axum 天文台** | ~100-130m | 罗塞塔石碑、针刺者巢穴、天青石 |
| **发电厂** | ~200m+ | 需控制论适应基因交互 |
| **Roots 峡谷** | 300m+ | 殖民者采矿遗迹、潜水电梯可达 |

::: tip 路线建议
前往遗迹废墟时**贴近海底前进**，以避免中途遭遇利维坦。Stay low, stay alive.
:::

## 枯萎边缘区 (B Nomadic Edge)

| 属性 | 值 |
|------|-----|
| **深度** | 250m+ |
| **危险等级** | 🟠 中-高危 |
| **核心资源** | 传导晶体 (Conduit Crystal)、锶 (Strontium)、陨铁 (Troilite) |
| **环境风险** | 毒性水体、枯萎病变异生物 |

轻度感染枯萎病的海域。生物开始变异，环境存在毒性。**终局资源的主要产地**。

## 虚空 (The Void)

| 属性 | 值 |
|------|-----|
| **深度** | ∞（无底） |
| **危险等级** | ☠️ 必死 |
| **核心资源** | 无 |
| **敌对生物** | 寒颤利维坦 (Shiver Leviathan) × 成群 |

地图边缘的生态"终结区"。雌雄二态性利维坦（雌性更大），群居猎食，深度达 5,000m。

::: danger
不要尝试探索虚空。这是地图边界，进入即死。
:::
