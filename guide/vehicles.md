# 载具指南

《深海迷航2》三种载具各有定位。获取顺序建议：**水波推进器 → 蝌蚪号 → 潜水电梯**。

![载具能力对比](/images/vehicles/vehicle-comparison.svg)

---

## 蝌蚪号 (Tadpole)

| 属性 | 值 |
|------|-----|
| **获取阶段** | 前期-中期 |
| **基础下潜** | 250m（无模块） |
| **最大下潜** | 400m+（含 Mk.2） |
| **速度** | 快 |
| **特点** | 模块化、可换底盘 |

《深海迷航2》的主力载具。单人模块化潜艇，取代前作的海蛾号。

**解锁**：扫描 3 个蝌蚪号碎片。

### 制造材料

蝌蚪号 = 钛锭 × 2 + 玻璃 × 1 + 系统芯片 × 1 + 动力电池 × 1

**配套建筑**：
- 蝌蚪坞 (Tadpole Dock) = 钛锭 × 2 + 银锭 × 1 + 铜线 × 2
- 月池 (Moonpool) = 钛 × 5（扫描第 2 个碎片后解锁）
- 载具装配台 = 钛锭 × 2 + 铜锭 × 1 + 玻璃 × 2

### 底盘变体

| 底盘 | 材料 | 用途 |
|------|------|------|
| 侦察型 (Scout Ray) | 塑钢锭×2 + 高级接线盒×1 + 专用核心×1 + 强酸×1 | 快速侦查、灵活机动 |
| 运输型 (Haul) | 钛锭×4 + 锶×3 + 珐琅玻璃×3 + 专用核心×1 | 大容量储物、多人搭乘 |

### 关键升级顺序

1. **深潜模块 Mk.1** — 先到 300m+，覆盖珊瑚礁带深层
2. **发动机效率** — 省电，延长单次出航时间
3. **撞击装甲** — 被针刺者/悬刺鱼攻击时减伤
4. **深潜模块 Mk.2** — 到 400m+，探索遗迹和枯萎边缘
5. **静默推进** — 经过收藏家利维坦领地时降噪
6. **光伏充电器** — 浅水区太阳能自动充电

### 使用技巧

- 蝌蚪号默认有一定储物空间，运输型更大
- **被收藏家利维坦缠上时立刻加速逃离**，不要回头
- 停在蝌蚪坞中自动充电
- 深潜模块 Mk.2 需要**陨铁 (Troilite)**，在枯萎边缘区深层获取

## 水波推进器 (Wakemaker)

| 属性 | 值 |
|------|-----|
| **获取阶段** | 前期 |
| **下潜深度** | 受氧气瓶限制 |
| **速度** | 中快 |
| **特点** | 可穿戴、即用即走 |

可穿戴水下推进器，替代初代的海蛾号作为前期代步工具。

**制造**：银 × 1 + 油脂 × 1 + 基础电池 × 1 + 接线盒 × 1

**解锁**：扫描 outpost 残骸中的水波推进器碎片。

### 使用场景

- 前期在安全区快速移动
- 采集资源时提高往返效率
- 蝌蚪号太大进不了的狭窄洞穴

### 局限

- 不提供额外氧气
- 无储物空间
- 无任何防护

## 潜水电梯 (Dive Elevator)

| 属性 | 值 |
|------|-----|
| **获取阶段** | 中后期 |
| **深度** | 300m+ |
| **速度** | 垂直移动 |
| **特点** | 对接基地、资源吊装 |

垂直运输平台，对接基地与载具。

### 核心用途

- 连接浅水基地与深海前哨
- 大容量资源垂直吊装
- Roots 峡谷 (300m+) 的必备通道

### 使用技巧

- 需要预先建造轨道（材料成本较高）
- 适合在基地和深海矿点之间建立固定运输线
- 配合蝌蚪号使用：电梯下潜 → 出电梯 → 蝌蚪号横向探索
