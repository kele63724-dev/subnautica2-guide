# Vehicles

Subnautica 2 features three vehicles. Recommended unlock order: **Wakemaker → Tadpole → Dive Elevator**.

![Vehicle Comparison](/images/vehicles/vehicle-comparison.svg)

---

## Tadpole

| Attribute | Value |
|-----------|-------|
| **Stage** | Early-Mid game |
| **Base Depth** | 250m (no modules) |
| **Max Depth** | 400m+ (with Mk.2) |
| **Speed** | Fast |
| **Trait** | Modular, swappable chassis |

Subnautica 2's primary vehicle. Single-seat modular submarine, replacing the Seamoth from the original.

**Unlock**: Scan 3 Tadpole fragments.

### Crafting

Tadpole = Titanium Ingot × 2 + Glass × 1 + System Chip × 1 + Power Cell × 1

**Supporting structures**:
- Tadpole Dock = Titanium Ingot × 2 + Silver Ingot × 1 + Copper Wire × 2
- Moonpool = Titanium × 5 (unlocks after 2nd fragment)
- Vehicle Fabricator = Titanium Ingot × 2 + Copper Ingot × 1 + Glass × 2

### Chassis Variants

| Chassis | Materials | Role |
|---------|-----------|------|
| Scout Ray | Plasteel Ingot×2 + Adv. Wiring Kit×1 + Dedicated Core×1 + Strong Acid×1 | Fast recon |
| Haul (Cargo) | Titanium Ingot×4 + Strontium×3 + Enameled Glass×3 + Dedicated Core×1 | Large storage, multi-passenger |

### Upgrade Priority

1. **Depth Module Mk.1** — reach 300m+, cover deep Coral Gardens
2. **Engine Efficiency** — longer trips
3. **Impact Armor** — reduce Needler/Hoverthorn damage
4. **Depth Module Mk.2** — reach 400m+, explore Ruins and Nomadic Edge
5. **Cavitation Silencer** — sneak past Collector Leviathan
6. **Photovoltaic Charger** — solar recharge in shallow zones

### Tips

- Tadpole has built-in storage; Haul chassis has more
- **If the Collector Leviathan grabs you, accelerate and don't look back**
- Docks in Tadpole Dock for automatic charging
- Mk.2 Depth Module requires **Troilite** from deep Nomadic Edge

## Wakemaker

| Attribute | Value |
|-----------|-------|
| **Stage** | Early game |
| **Depth** | Limited by air tank |
| **Speed** | Medium-Fast |
| **Trait** | Wearable, instant use |

Wearable underwater propulsion, replacing the Seaglide from Subnautica 1.

**Crafting**: Silver × 1 + Grease × 1 + Basic Battery × 1 + Wiring Kit × 1

**Unlock**: Scan Wakemaker fragments at outposts.

### Use Cases

- Fast travel in safe shallows
- Efficient resource gathering runs
- Navigating tight caves where the Tadpole won't fit

### Limitations

- No oxygen supply
- No storage
- No protection whatsoever

---

## Dive Elevator

| Attribute | Value |
|-----------|-------|
| **Stage** | Mid-Late game |
| **Depth** | 300m+ |
| **Speed** | Vertical only |
| **Trait** | Base-to-base transport, resource hauling |

Vertical transport platform connecting bases and vehicles.

### Core Uses

- Connect shallow base to deep outpost
- Heavy resource vertical hauling
- Essential access for Roots Canyon (300m+)

### Tips

- Requires pre-built track (high material cost)
- Ideal for fixed transport lines between base and deep mining sites
- Pair with Tadpole: elevator down → disembark → Tadpole for horizontal exploration
