# 바이옴

얼리 액세스에서 **6개 바이옴**이 Ariadne Arm 구역에 개방. 최종 맵은 1편 + Below Zero 합계보다 더 광대.

![바이옴 심도 분포도](/images/biomes/biome-depth-map.svg)

---

## 켈프 숲 (Kelp Forest)

| 속성 | 값 |
|------|-----|
| **수심** | 0 - 60m |
| **위험도** | 🟢 안전 |
| **주요 자원** | 티타늄, 구리, 석영, 소금, 루시퍼 롯삭 |
| **적대 생물** | 대형 포식자 없음 |

시작 지점. 빛이 풍부하고 기초 자원이 밀집.

---

## 산호초 지대 (Coral Gardens)

| 속성 | 값 |
|------|-----|
| **수심** | 0 - 200m |
| **위험도** | 🟡 저-중 |
| **주요 자원** | 석영(산호 돔 내부 다량), 은, 금, 황, 구리, 납 |
| **적대 생물** | 소형 공격 생물 존재 |

초반 가장 중요한 자원 지대. 서브 바이옴:

| 서브 바이옴 | 수심 | 주요 자원 |
|-------------|------|-----------|
| **얕은 여울** | 0-50m | 석영 (스파이더 돔에 ~100 노드) |
| **해파리 불모지** | 50-200m | 구리, 네크롤레이 시스트 |
| **아네모네 언덕** | 얕음-중 | 은, 내열 유전자 샘플링 |
| **사암 능선** | 얕음-중 | 납 (가장 신뢰할 수 있는 공급원) |
| **투파 타워** | 얕음-중 | 그레이트 조 레비아탄, 잔해 |
| **Zezuran 사막** | 중, 열동굴 200-250m | 금, 황, 리튬 |

---

## 황량 평원 (Sparse Plains)

| 속성 | 값 |
|------|-----|
| **수심** | 100 - 300m |
| **위험도** | 🔴 높음 |
| **주요 자원** | 구리, 티타늄, 납 |
| **적대 생물** | ☠ 컬렉터 레비아탄 |

::: danger 컬렉터 레비아탄 대책
- 길이 50m+, 오징어 형태, 4개 촉수(잡기/압착/타격/충격파)
- **죽일 수 없음**(설계상) — 회피만 가능
- 실시간 AI가 동적 위치 평가
- **탈출**: 45,000 유닛 거리 확보 시 소멸, 또는 디코이 플레어로 주의 분산
:::

## 유적지 (Overgrown Ruins / Axum 구역)

| 속성 | 값 |
|------|-----|
| **수심** | 200 - 400m+ |
| **위험도** | 🟠 중-고 |
| **주요 자원** | 셀레스틴, 아타카마이트, 컨듀잇 크리스탈 |
| **적대 생물** | 니들러 망고 |

고대 알테라 건축물군. 고급 설계도와 스토리 단서 보유.

| 구역 | 수심 | 비고 |
|------|------|------|
| **Axum 천문대** | ~100-130m | 로제타 스톤, 니들러 둥지 |
| **발전소** | ~200m+ | 사이버네틱 적응 필요 |
| **Roots 협곡** | 300m+ | 식민지 광부 유적, 다이브 엘리베이터 |
