## 태드폴 (Tadpole)

| 속성 | 값 |
|------|-----|
| **단계** | 초-중반 |
| **기본 심도** | 250m |
| **최대 심도** | 400m+ (Mk.2) |
| **속도** | 빠름 |
| **특징** | 모듈식, 섀시 교환 가능 |

Subnautica 2의 주력 탈것. 1인승 모듈식 잠수정.

**해금**: 태드폴 파편 3개 스캔.

**제작**: 티타늄 주괴 × 2 + 유리 × 1 + 시스템 칩 × 1 + 파워 셀 × 1

### 섀시 변형

| 섀시 | 재료 | 용도 |
|------|------|------|
| 스카우트 레이 | 플라스틸×2 + 고급 배선 키트×1 + 전용 코어×1 + 강산×1 | 고속 정찰 |
| 홀 (수송) | 티타늄 주괴×4 + 스트론튬×3 + 에나멜 유리×3 + 전용 코어×1 | 대용량 수납 |

### 업그레이드 우선 순위

1. **심도 Mk.1** — 300m+, 산호초 지대 심층부
2. **엔진 효율** — 항속 시간 연장
3. **충격 장갑** — 니들러 등 공격 경감
4. **심도 Mk.2** — 400m+, 유적지·유목 경계
5. **정숙 추진** — 컬렉터 레비아탄 영역 통과용
6. **광기전력 충전기** — 천해역 태양광 충전

## 웨이크메이커 (Wakemaker)

| 속성 | 값 |
|------|-----|
| **단계** | 초반 |
| **심도** | 산소 탱크 의존 |
| **속도** | 중-고속 |
| **특징** | 착용식, 즉시 사용 |

착용식 수중 추진기.

**제작**: 은 × 1 + 그리스 × 1 + 기본 배터리 × 1 + 배선 키트 × 1

- ✓ 안전한 천해역 고속 이동
- ✓ 자원 채집 왕복 효율
- ✗ 산소 공급 없음
- ✗ 수납 없음
- ✗ 방어 없음

## 다이브 엘리베이터 (Dive Elevator)

| 속성 | 값 |
|------|-----|
| **단계** | 중-종반 |
| **심도** | 300m+ |
| **속도** | 수직 방향만 |
| **특징** | 기지 간 수송, 자원 양중 |

- ✓ 고속 수직 승강
- ✓ 기지와 심해 전초기지 연결
- ✓ 대용량 자원 수송
- ✗ 수직 이동만
- ✗ 궤도 부설 필요
