## S급 위협 — 레비아탄

### 컬렉터 레비아탄 (Collector Leviathan)

| 속성 | 값 |
|------|-----|
| **길이** | 50m+ |
| **분류** | 레비아탄 (두족류) |
| **서식지** | 황량 평원, 외곽 경계 |
| **공격** | 4개 촉수 — 잡기/압착/타격/충격파 |
| **AI** | 실시간 동적 평가, 고정 스크립트 아님 |

**EA 유일의 공격적 레비아탄. 죽일 수 없음(설계상).**

**대처법**:
- 🛡️ **45,000 유닛** 거리 확보 시 소멸 판정
- 🛡️ **디코이 플레어**로 일시적 주의 분산
- 🛡️ 태드폴 **정숙 추진**으로 탐지 위험 감소
- ❌ 싸우려 하지 말 것

## 소형 생물

### 문피쉬 과

| 이름 | 용도 |
|------|------|
| **하프문** | 기본 식량 |
| **블루문** | 식량, 하프문과 무리 |
| **하베스트문** | 삼월초밥의 핵심 재료 |
